# 관리자 서비스 프로토타입

관리자 화면 설계를 확인하기 위한 정적 HTML 프로토타입이다. 화면의 수치·계정·기록은 모두 시연용 예시 데이터이며 서버와 연결되어 있지 않다.

- 보기: https://bc8c.github.io/munhwa-admin-prototype/
- 상단 바에서 역할(A2·A3·A4)을 바꿔 역할별 메뉴와 화면을 볼 수 있다. 새로고침하면 처음 상태로 돌아간다.
- 로그인 화면의 예시 계정은 카드 아래 안내와 상단 바에 표시된다.

이 저장소는 배포본만 둔다. 편집 원본은 별도로 관리하며, `index.html`은 빌드 결과물이다.
